## 📌 Project Overview

This project analyzes sample banking data using Python to explore customer demographics, account balances, account types, transaction amounts, and city-wise customer distribution. It uses data analysis and visualization to identify patterns and summarize banking information.

## 🎯 Project Objectives

- Calculate the total number of customers.
- Analyze average, maximum, and minimum account balances.
- Compare customers across different account types.
- Explore transaction amount distributions.
- Compare account balances across cities.
- Visualize relationships between balances and transaction amounts.

## 🛠️ Technologies Used

- **Python** – Programming and analysis
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical calculations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization

## 📊 Dataset Information

The dataset contains 30 fictional banking customer records.

| Column | Description |
|---|---|
| `Customer_ID` | Sample customer identifier |
| `Age` | Customer age in years |
| `Gender` | Customer gender |
| `Account_Type` | Savings, Current, or Salary |
| `Balance` | Illustrative account balance |
| `Transaction_Amount` | Illustrative transaction amount |
| `City` | Customer's sample city |

**Note:** This dataset contains fictional sample data for educational purposes. It does not represent real customers, bank accounts, or transactions.

## 📈 Analysis and Visualizations

The project includes:

- Customer distribution by account type
- Average balance by account type
- Balance comparison by city
- Transaction amount distribution
- Balance vs. transaction amount analysis
- Summary statistics using Pandas and NumPy

## ⚙️ Installation

Install the required libraries:

```bash
python -m pip install pandas numpy matplotlib seaborn
```

## ▶️ How to Run

1. Clone or download the repository.
2. Ensure `banking_data.csv` is inside the `data` folder.
3. Open a terminal in the project directory.
4. Run the Python script:

```bash
python banking_analysis.py
```
